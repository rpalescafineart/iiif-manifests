Workflow Tools and Templates

This directory contains the scripts and templates used to generate and publish IIIF manifests for the RPalesca Fine Art digital archive workflow. All files below can be viewed or downloaded directly.

To download a file, right-click the link and choose “Save link as…” (or similar in your browser).

Metadata Templates

File Description
collection-template.csv CSV template for preparing collection metadata prior to manifest generation.
iiif-prep-template.csv IIIF-ready CSV template that includes image URLs, thumbnail paths, and rights metadata.

Python Scripts

File Description
generate-thumbs.py Generates thumbnails for each artwork image, used in manifests and viewers.
make_manifests_with_thumbs.py Reads a metadata CSV and creates IIIF Presentation v3 manifest JSON files and folder structure.

Documentation & Examples

File Description
README.txt Text documentation describing how to use these tools and templates.
sample-manifest.json Example IIIF manifest file demonstrating the expected output structure.
